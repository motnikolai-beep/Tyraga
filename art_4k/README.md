# Арт v12 «Borderlands × реальность», 4K

## Что здесь
- `locations/` — 12 фонов локаций, 3840×2160.
- `characters/` — 18 портретов NPC и портрет игрока (`19_hero.jpg`), высота 3840 (обычно 2880×3840).
- `preview/` — листы «было → стало» и `cast_in_game.jpg`: как портреты выглядят в собранной игре.

## Как это попадает в игру
- `python build_v12.py` берёт картинку из `art_4k/<папка>/<имя исходника>.jpg`. Если её нет, берётся исходный PNG из `первая половина/`.
- Чтобы вернуть герою или локации оригинал, удалите соответствующий файл из `art_4k/` и пересоберите игру.
- В сборке у каждого героя свой файл портрета `assets/<id>.jpg`. Сборка останавливается, если у двух героев или двух локаций оказалась одна и та же картинка.
- Перед боем с боссом игра показывает заставку: портрет, имя, локация и короткая подпись (`bosscard.py`, подписи — `TAGLINES` в `build_v12.py`).

## Состояние
- Локации: 12 из 12. Боссы: 12 из 12, по одному на локацию. Остальные NPC: 6 из 6; отдельно герой игрока: 1 из 1.
- Четыре босса придуманы для v12, исходных картинок у них не было: Полкан (`15_polkan`, двор), Хлеборез (`16_hleborez`, кухня), Кипяток (`17_kipyatok`, душевая), Цензор (`18_tsenzor`, библиотека). На листе «было → стало» слева у них пометка «новый герой».
- У Зинаиды исходной картинки тоже не было (раньше она показывала портрет Матери-Смотрительницы): её облик придуман заново.
- Портрет игрока нарисован по исходнику `assets/player_avatar_custom.png`: полный мастер `19_hero.jpg`, игровая версия `assets/player.jpg`; на экране «Личное дело» и в сценах рассказчика показывается он.
- Игра, запущенная прямо из корня репозитория, берёт портреты новых боссов из `assets/<id>.jpg`. Если заменили мастер нового босса, пересоздайте этот файл: тест `tests/test_art4k.py` напомнит.

## Как сделано
- Каждая картинка — перерисовка исходника нейросетью (около 1K) и увеличение в 4 раза моделью Upscayl Lite. Это не нативный 4K-рендер.
- Каждый герой стоит на фоне своей локации.
- Известные огрехи: каракули вместо букв на ящиках у Цепей, на пакете у Курсанта и в наколках Хлебореза; коридор стилизован слабее остальных локаций.
- У Полкана вручную убран чернильный контур вокруг облачка пара изо рта.

## Как добавить или заменить картинку
```
pip install pillow numpy ncnn
python tools/art4k.py chr 07_kulibin путь/к/перерисовке.png   # портрет
python tools/art4k.py loc 04_corridor путь/к/перерисовке.png  # локация
python tools/art4k.py audit      # что готово и нет ли повторов
python build_v12.py              # собрать игру
python tools/art4k.py preview    # обновить листы предпросмотра
```
