# Идеи и долги для v12
1. Живая проверка на Windows: меню, карта, окно боя (кадры), клавиши на русской раскладке, звук (MCI).
2. Спрайты вместо векторных силуэтов (prompts и import_art.py готовы), портреты 14 NPC, фон меню.
3. Баланс боя в живой игре; обучение бою; режим тренировки.
4. Контекст ИИ: итоги боя и травмы в репликах NPC.
5. Сборка в exe и установщик с моделью.
6. Новые приёмы: захваты, броски, спецприёмы по стилю босса.
