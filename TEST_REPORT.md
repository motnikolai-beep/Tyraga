# Отчёт о проверке v11
Автоматические тесты (pytest): 69 прошли — ядро, сюжет (все сцены проходятся случайным прохождением), меню/слоты/настройки/достижения, v10 (лор, события, цены, дела, слабости, концовки, звук-генерация), бой (части тела, блок/парирование, комбо, кувырок, сигарета, стили боссов, исходы, лимит времени), UI на заглушке Tk (меню, окно боя, чат, карточки, туториал).
Симуляция боя ботом: исходы разнообразны (часть боссов побеждается чаще, часть реже), бой длится 20-35 с.
НЕ проверено: реальное окно Tk, Windows, GPU, llama.cpp, звук, внешний вид анимации, ощущение управления.
