# Инструкция v8

## Запуск
* Windows: `START.bat` (создаёт `.venv`, ставит Pillow, запускает `main.py`).
* Вручную: `pip install -r requirements.txt` затем `python main.py`.
* Нужен Python 3.10+ с tkinter. Модель и llama-server — по путям из `.env`
  (`SCOUT_MODEL_PATH`, `SCOUT_MMPROJ_PATH`, `SCOUT_PORT`).

## Экраны и клавиши
| Клавиша | Что делает |
| --- | --- |
| Q | сюжетная сцена (если вы в нужной локации и время подходит) |
| M | карта зоны, клик по объекту — переход |
| A | действия в текущей локации |
| I | сумка, снаряжение, покупки |
| J | журнал: сюжет, каста, дневник, слухи, события |
| F2 | полная история разговора |
| Esc | закрыть окна |
| Ctrl+S | сохранить |

## Время
* 1 игровая минута = 3 секунды реального времени, когда вы ничего не делаете.
* Кнопка «⏸ Время» останавливает и возобновляет.
* Дела стоят времени: смена 120 мин, уборка 90, поиск схрона 30, перекур 5,
  разговор 3–35 мин в зависимости от длины.
* Расписание: завтрак 07:00–08:30, обед 12:00–13:30, ужин 18:00–19:30, отбой 22:00.
* Сон: только в камере и только после 21:00. День сменится на 07:00.

## Каста и уважение
* Уважение 0–100. Каста считается по уважению и трофеям.
* Вверх: помощь, работа, дела, победы, честные ответы.
* Вниз: унижения, шмон с контрабандой, стукачество, провалы «по понятиям».
* Клеймо петуха снимается подъёмом уважения и храмом.

## Храм
* «Помолиться»: 2 раза в день, чистит до 12 очков отрицательной кармы,
  при отрицательной карме может снять часть унижений.

## Боссы
* ★ на карте. Слабость указана в `data.BOSSES`.
* Победа: +14 уважения, трофей, публичное событие, ★ меняется на ✕,
  остальные NPC относятся осторожнее (уходит в контекст ИИ).

## Сохранения
* `saves/town_v4.json`, автосохранение каждые 30 секунд и после действий.
* Файлы v7 читаются автоматически (`cig` переносится в сумку, `ap` убирается).
* Старые сохранения лучше забэкапить: `saves/town_v4.json.bak`.
